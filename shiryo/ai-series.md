# AIシリーズの資料

2回目以降の記事を書くときは、このファイルと CLAUDE.md・neta.md を読んでから書く。
ここに書いていない体験や意見は、えびおに聞いてから書く（勝手に足さない）。

## シリーズ案（全8回の予定。1回に詰め込まず、分けて書く）
① 人差し指一本の私がブログを再開できたのは、AIのおかげでした（ブログ再開のあいさつ、AIとの付き合い方、シリーズの予告）
② AIはどれを使えばいい？ChatGPT・Gemini・Claude の違いと選び方（種類、得意なこと、料金）
③ せどりのリサーチにAIを使う
④ お客さんとのメールをAIに手伝ってもらう
⑤ 発注伝票などの書類づくりをAIで
⑥ 商品画像・販売ページをAIで作る（Amazon・楽天・Yahoo!ショッピング。画像の作成や修正も）
⑦ Claude Codeで自分専用の作業ツールを作る（えびおの実例：出荷CSV、出品前チェッカー、楽天の日報）
⑧ AIを使うときの注意点（規約、個人情報、AIのまちがい、やらせの口コミにしない）

## えびおの話（シリーズ①の材料。ここにないことは足さない）
・ブログを再開しようと思ったのは、今はAIがあって、自分がアイデアを出すとブログの形に考えてくれるから。AIがなかったら、たぶんやろうと思っていない。
・自分で文章を直したり、文字を打ったりするのはとても苦手。いまだに人差し指一本で打っているくらい。
・今の時代、物販でAIを使うのは必須だと思っている。
・AIは、せどりでは、たとえばリサーチ、お客さんとのメールのやり取り、発注伝票の作成に使える。ほかにもできる作業は多い。
・自分はClaude Codeで作業ツールをいろいろ作っている（出荷のCSV作成、出品前の規約チェック、楽天の日報づくり など）。こういうツール作りは、Claude Codeでないと難しいと思っている。
・一方で、GeminiやChatGPTなど普通のAIでも、画像を作る・直す、Amazon・楽天・Yahoo!ショッピングの販売ページを作る、といった使い方ができる。
・AIは1回で説明しきれないので、何回かに分けて書いていく。
・テーマは「AIとの付き合い方」。

## 参考資料の注意点（えびおのPDF資料を見て気づいたこと。②以降で使う）
・資料の一部で「CloudCode（雲のマーク）」と書かれているところがあるが、正しくは「Claude Code（クロード・コード）」。Google の「Cloud Code」という別の道具があるので、記事では混ぜない。
・資料の「VS Code の Cloud Code と Gemini Code Assist」で画像アプリを作る話は、Google の道具の話。Claude Code の話と分けて書く。
・AIの比較表にある星の点数（4.5／5 など）は、資料を作るときの目安で、公式の評価ではない。記事では点数として書かない。
・Claude の料金（Pro 月20ドル、Max 月100ドル・200ドル）は変わることがあるので、書くなら【要確認：今の料金】をつける。
・Claude Code の発表は2025年2月（お試し版）、正式版は2025年5月。
・楽天RMSでCSSを入れる手順や、使えるタグの決まりは変わることがあるので、書くなら【要確認：今の手順と決まり】をつける。
・SNS動画の「お客様の声」をAIで作る例は、本当の声でなければ、やらせ（ステマ）や誇大な表示になるおそれがある。⑧で注意として書く。
